项目概览 / PROJECT OVERVIEW
1. 10×10 双人海战棋：规则逐条对齐，做了三版迭代。
2. 霓虹方块：幽灵预览、消行计分，没有框架。
3. 退房时间：三间客房，一个雨夜，剧情和空间一起搭。
4. 雷霆战机：美术、音效、特效、玩法分成四层。
5. 长征 · 从瑞金到会宁：七个坐标，纸感排版，一张会问问题的地图。

技术与玩法 / TECH & DESIGN
1. 海战棋：HTML / CSS / JS 手写规则与判定。
2. 霓虹方块：纯 Canvas 2D，自己写下落、消行、计分。
3. 退房时间：第一人称 3D 场景，靠叙事推进。
4. 雷霆战机：四层拆分，两种模式共用一套玩法。
5. 长征地图：地图问答与纸感排版，都是手写的样式。

个人贡献 / MY PART
1. 五个项目都是一个人做完的：策划、代码、素材、调试。
2. 尽量不用框架，先把手写的那版跑通。
3. 做完了才拿出来，不放效果图。
